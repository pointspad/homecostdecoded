Privacy Policy

HomeCostDecoded Poster — last updated 13 August 2026.

HomeCostDecoded Poster is a private tool used by one person to upload their own videos to their own TikTok account. It is not offered to other users and has no customers.

What it does

The tool authenticates with TikTok using TikTok's Login Kit and uploads video files to the account holder's own TikTok drafts using the Content Posting API (video.upload). Videos arrive as drafts; they are reviewed and published manually inside the TikTok app.

What is collected

No personal data is collected from anyone. The tool stores a single OAuth access token for the account holder's own TikTok account, on the account holder's own computer, readable only by that user account. Nothing is transmitted to any third party, no analytics are gathered, no data is sold or shared, and there is no server or database.

Data from TikTok

The user.info.basic scope is granted by TikTok alongside Login Kit. Any profile information returned is used only to confirm the correct account is connected, and is not stored beyond the session.

Retention and deletion

The stored token can be deleted at any time by removing the local credentials file, or by revoking the app under TikTok Settings → Security & permissions → Manage app permissions.

Contact

Questions about this policy can be sent to the account holder via the Home Cost Decoded YouTube channel.
